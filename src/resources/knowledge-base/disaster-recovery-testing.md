# Teste de disaster recovery

O plano de backup só existe se alguém já restaurou. O ensaio usa uma cópia ou uma região de ensaio, com hora de backup conhecida.

RPO é o quanto de dado pode se perder. RTO é o tempo até o serviço aceitar um smoke. Os dois são números do ensaio, não do documento.

O smoke na cópia restaurada prova que a aplicação sobe. Arquivo de backup que existe e não restaura não conta. O ensaio não aponta para o banco que serve o cliente.
