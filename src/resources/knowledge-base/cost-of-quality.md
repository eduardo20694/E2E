# Custo da qualidade

Achar o mesmo defeito custa mais quanto mais tarde ele aparece. Um modelo simples de planejamento usa pesos relativos: desenvolvimento 1, QA 5, staging 15, produção 50. São pesos para comparar, não uma lei medida em todo time. Se o time tem o próprio número, o número do time ganha.

Automatizar vale quando o caso roda bastante, o fluxo não muda toda semana e a manutenção não come a economia. Tela frágil com execução rara fica manual, e a regra por baixo vai para o unitário.
